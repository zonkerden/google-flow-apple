# Google Flow (Apple Design Edition)

A high-fidelity web application concept combining Google's Flow AI capabilities (Veo video and Imagen generation) with pristine Apple Human Interface Guidelines (glassmorphism, SF Pro typography, rounded card geometry, and smooth bottom sheets).

## Tech Stack
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**

## Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/google-flow-apple.git
   cd google-flow-apple
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
